# Лендинг Аэротон

Статическая страница (HTML, CSS, JS), публикуется через GitHub Pages. Пока домена нет, страница закрыта от поисковиков (noindex и robots.txt). Все пути относительные, поэтому страница работает и по адресу проекта, и на собственном домене.

Привязка домена: добавить файл CNAME с адресом домена, настроить DNS у регистратора, включить «Enforce HTTPS». Перед запуском убрать `noindex` из `index.html` и `privacy.html` и очистить `robots.txt`.
